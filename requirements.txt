# VeritasQA V1 baseline: runtime and test dependencies (pinned). Decision D17, 2026-11-04.
# Install into a Python 3.11+ virtual environment:  python -m pip install -r requirements.txt
#
# This file is the whole V1 dependency plan: a deterministic, LLM-free, embedding-free pipeline.
# It installs and passes the test suite without PyTorch, NumPy, spaCy, NLTK or any model.
# Other groups are separate files (docs/ARCHITECTURE.md §7, docs/SETUP.md):
#   requirements-experimental.txt  optional TF-IDF baseline (benchmark-only); spaCy/NLTK and rapidfuzz await Q6
#   requirements-gpu.txt           historical P0-ENV group, removed from the V1 plan; do not install for V1
# No module of the baseline pipeline imports an optional or historical group (SPEC §1, §4, §13; D17).
#
# Why these and not others:
# - pymupdf is pinned to 1.26.6 on purpose. PyMuPDF 2.x pulls in onnxruntime, numpy, networkx,
#   pymupdf4llm and pymupdf_layout, none of which the extractive baseline needs. 1.26.6 declares
#   no dependencies of its own.
# - PyMuPDF is licensed AGPL-3.0 or commercially. Review that before distributing the project.
# - No generative or hosted model dependency exists anywhere in this list (SPEC §1).
